# Contributor guidance for agents

Read [CONTRIBUTING.md](CONTRIBUTING.md) for setup, checks, architecture boundaries and documentation maintenance. See [MISMATCH.md](MISMATCH.md) for known discrepancies and verification limits.

Keep `docs/` private and Gitignored. Do not copy private specifications, research, audit logs, historical evidence, credentials or applicant data into tracked files or source comments. Preserve original evidence before consolidating historical documentation.
