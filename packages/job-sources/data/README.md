# Starter employer directory

`Rovdo_Starter_Directory.json` is the supplied release of 9,935 employer ATS board
candidates, not individual job postings. Startup retains five additional legacy entries
and preserves established identities and reviewed metadata for matching boards.

Source crawl dates are July 11 through August 1, 2026. They do not establish current
live verification, collection permission or open postings. Date-only source values are
encoded as midnight UTC. The 31 source slugs containing periods remain unsupported
by the current tenant matcher and visible as coverage gaps.
