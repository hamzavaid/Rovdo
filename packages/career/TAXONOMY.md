# Rovdo technical taxonomy

`rovdo-taxonomy-2` is a small, original curated English technical vocabulary. Stable local IDs, typed aliases, role families and directed relationships follow the modeling approach of [O*NET](https://www.onetcenter.org/database.html) and [ESCO](https://esco.ec.europa.eu/en/classification). It is not a complete copy, official mapping or endorsement by either project. No external ESCO concept URI is invented or implied.

Language, framework, runtime, database, cloud, tool and library types remain distinct. An ecosystem relationship alone gives no substitution credit. The explicitly curated `implies` relationships are one-way, configurable partial credit; exact aliases retain full identity. Short ambiguous names require skill context. Versions are separate from concept IDs. Unknown aliases and unsupported version expressions remain unresolved.

Weights and thresholds are engineering defaults for validation, not measured hiring accuracy or probabilities.

Version 2 adds curated embedded/FPGA/ASIC/robotics and development-tool terms. Ordinary-word aliases require skill context. Import recognition suppresses incidental and negated mentions; contextual proposals remain unverified. Stable existing IDs and directional matching rules are retained. Taxonomy version changes invalidate ranking caches while older snapshots remain readable.
